# Logistics

## How to update the site

1. Edit Markdown files under `src/pages/`.
2. Commit and push to `main`.
3. GitHub Actions builds Astro and deploys `dist/` to GitHub Pages.

## Good defaults

- Keep schedule rows short.
- Put longer commentary in `src/pages/notes/YYYY-MM-DD-paper.md`.
- Use Markdown tables for schedules and paper queues.
- Prefer stable paper links: arXiv, ACM, USENIX, authors' pages.

## Repository settings

In GitHub, enable Pages with:

- **Settings → Pages → Source:** GitHub Actions
